# Лабораторная работа №2. Простой сайт на Django

**Вариант 2:** «Доска домашних заданий»

Сайт, на котором преподаватели выдают домашние задания, студенты сдают их в текстовом виде, а оценки собираются в общий журнал группы.

## Возможности

**Студент**
- регистрация и вход, выбор группы;
- список заданий своей группы со сроками, описанием и штрафами;
- поиск по заданиям, фильтры по предмету, сроку и статусу («не сдано», «на проверке», «оценено»);
- сдача работы в текстовом виде, изменение или отмена до проверки;
- раздел «Мои сдачи» с оценками и комментариями преподавателя;
- журнал оценок своей группы.

**Преподаватель**
- выдача, редактирование и удаление заданий для одной или нескольких групп;
- очередь проверки с рекомендуемой оценкой с учётом штрафа за просрочку;
- выставление оценок на сайте и в Django Admin;
- журнал оценок любой группы.

Интерфейс сделан на Bootstrap. В списках есть пагинация, поиск и фильтры. Права разделены на сервере и в шаблонах: преподаватель определяется по флагу `is_staff`.

## Запуск

1. Установить зависимости:
   ```bash
   python -m venv venv
   source venv/bin/activate        # Windows: venv\Scripts\activate
   pip install -r requirements.txt
   ```
2. Создать в PostgreSQL базу `homework_board`. Параметры подключения задаются переменными окружения
   `DB_NAME`, `DB_USER`, `DB_PASSWORD`, `DB_HOST`, `DB_PORT`.
3. Применить миграции, загрузить демо-данные и запустить сервер:
   ```bash
   cd homework_board
   python manage.py migrate
   python manage.py seed
   python manage.py runserver
   ```
4. Открыть http://127.0.0.1:8000
