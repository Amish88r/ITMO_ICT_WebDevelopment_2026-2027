## Цель работы

Овладеть практическими навыками и умениями реализации web-сервисов средствами Django.

## Используемые технологии

| Компонент | Версия |
|---|---|
| Python | 3.11+ |
| Django | 5.2 |
| СУБД | PostgreSQL 16 |
| Вёрстка | Bootstrap 5.3 + Bootstrap Icons (подключены локально) |
| Отчёт | MkDocs + Material |

## Структура репозитория


## Что реализовано

- практические работы 2.1, 2.2, 2.3 — модели автовладельцев, FBV и CBV, формы, кастомный пользователь;
- сайт «Доска домашних заданий» на PostgreSQL:
    - регистрация, вход, профиль;
    - просмотр ДЗ по всем предметам со сроками и описанием;
    - сдача ДЗ в текстовом виде, редактирование и отмена своей сдачи до проверки;
    - выставление оценок преподавателем в Django Admin (и в клиентском интерфейсе);
    - таблица оценок всех студентов группы;
- **на максимальный балл:** стилизация Bootstrap, пагинация, поиск и фильтрация, разделение прав
  студента и преподавателя в клиентском интерфейсе (`is_staff`).
